# WariMitra AI (वारीमित्र)

WariMitra AI is a prototype **voice-first assistant** built for Warkaris (pilgrims) during the Pandharpur Wari pilgrimage.

No smartphone or app installation required — users can speak naturally in Marathi to find:

- Nearest medical facilities, doctors, and pharmacies
- Water stations and sanitation facilities
- Food and shelter locations
- Missing person alerts and community updates

## Tech Stack

- [TanStack Start](https://tanstack.com/start)
- TypeScript
- Tailwind CSS
- Google Gemini AI
- Web Speech API (voice input/output with Marathi support)

## Prototype Status

This repository currently includes demo data.

Production deployment will require:

- A real facility database
- Backend integration with emergency services
